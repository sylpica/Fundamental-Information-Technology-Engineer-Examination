## その他の確認（抜粋）

- why を書き換えた誤答は、すべて書かれた導出で選択肢の値が出た。例：A06-509 の 4.0 V（0.5×8）、A06-516 の 800（40×20）、A06-009 の 2 倍（反比例と取り違え）、A08-502 の 49.8（49,766,400 ビットをバイト扱い）、A09-021 の 4、A09-025 の 4・2、A09-501 の（6，3）、A09-511 の（6，1，3，1）、A10-005 の 8、A10-006 の 80・0.8、A10-508 の 4.8、A10-525 の 0.24・1.2・0.012、A11-045 の 50 万円、A11-506 の 0.8 時間。
- 式に変えた verify は、どれも問題の数値から正答値を導いていた。tolerance を付けたもの（A08-501・502・508 は 0.05、A11-525 は 0.1）も、他の選択肢の値は許容範囲に入らない。
- topic を変えた問題（A10-515〜529、A11-515〜530 など）は、シラバスの項目説明・用語例と照合した。いずれも内容に合っている（例：CSMA/CD→10-2-5、VLAN→10-3-1-2、耐タンパ性→11-3-1、中間 CA 証明書→11-1-8-5）。
- diff の引下げ（3→2、4→2 など）と hard の削除は、解答が 1〜2 段階の判断で済む問題に限られていた。CONTENT_GUIDE の基準に照らして妥当。
