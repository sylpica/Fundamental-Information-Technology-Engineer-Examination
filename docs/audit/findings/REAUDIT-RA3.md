## A04-501 と A04-515 の判定：実質重複のため A04-515 を改題

- A04-501：入口装置 0.98、処理サーバ 0.90 の 2 台並列、DB 0.95 の直列。並列部分を 0.99 に換算してから直列の積を取る。
- A04-515（旧）：0.99、0.98、0.995 の直列のうち 0.98 の要素を二重化。並列部分を 0.9996 に換算してから直列の積を取る。

どちらも「3 要素の直列のうち 1 要素を 2 台並列にして、並列換算 → 直列の積」という同じ 2 段階の計算である。「改善後」という言い方と数値が違うだけで、学習内容は同じ。基本形の A04-030（04-system.yaml）とも同じ系統になる。A04-501 は担当外のファイルにある基本の H2 版として残し、A04-515 を作り直した。

**改題後の A04-515**：稼働率 0.95 の X と 0.9 の Y の直列系に X・Y を 1 台ずつ足すとき、構成 1（X–Y の系統を 2 系統並列にする＝系全体の二重化）と構成 2（X の並列部分と Y の並列部分を直列にする＝装置ごとの二重化）の稼働率の組合せを問う。

- 解き直し：X–Y の直列 0.855。構成 1＝1−(1−0.855)²＝0.978975≒0.979。構成 2＝(1−0.05²)×(1−0.1²)＝0.9975×0.99＝0.987525≒0.988。正答「構成 1 が約 0.979、構成 2 が約 0.988」（位置ウ。旧版と同じ）。
- 誤答：二つの構成の値の取り違え（0.988／0.979）、台数が同じなら稼働率も同じとする誤解（どちらも 0.988）、2 系統を直列とみなす計算（0.855²≒0.731）。
- 新しく学べること：直列と並列を合成する順序。同じ台数なら、装置ごとに二重化する方が系全体を二重化するより稼働率が高くなる。
- 重複の確認：稼働率の問題（A04-028〜030、A04-501〜503・509・520・521・524・527、A15-011・012・501・512・514・518）を全部見た。系全体の二重化と装置ごとの二重化を比べる問題はなかった。
